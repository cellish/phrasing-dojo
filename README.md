# フレージング道場 / Phrasing Dojo

旋律の抑揚（フレージング）を解釈する力を鍛えるブラウザ用ドリルです。

- **クラシック編**：フレーズの頂点を選ぶ「山はどこ？」と、3通りの抑揚を聴き比べる「聴き比べ」。10の原則を4つの種類に分けています。
  - フレーズの形：弓なり形と終止、跳躍と最高音、反復とゼクエンツ、フレーズの入れ子
  - 和声：倚音と解決、和声の緊張
  - 拍とリズム：弱起、反復音
  - 時間と音のつなぎ方：時間の取り方、スラーのまとまり
- **ジャズ編**：アクセントやゴーストノートを置く音を選ぶ「アクセントはどこ？」と「聴き比べ」。11の原則を3つの種類に分けています。
  - アクセント：裏拍のアクセント、線の頂点、先取り、ゴーストノート、短い終わり
  - リズムの種類：3連符、3つずつのフレーズ、ボサノヴァ、ダブルタイム
  - タイム感：ビートとの位置（レイドバック、オントップ、休符のあとの入り）、ハネの深さ

音はブラウザ内で合成したピアノで、ジャズ編ではライドシンバル、ウォーキングベース、コードのバッキング（ボサノヴァは専用のリズム隊）を重ねられます。

画面の言語は日本語と英語、テーマは自動・ライト・ダークを、右上の「設定」から切り替えられます（最初はブラウザの設定に従います）。

## English

A browser drill for interpreting melodic phrasing. The classical edition (10 principles) asks you to find the peak of a phrase and compare three shaped versions; the jazz edition (11 principles) asks you to mark accents and ghost notes in swing lines and compare articulations, triplets, bossa nova, double time and time feel. The interface switches between Japanese and English and follows the browser language by default.
